# v2.4.5-kr1 — серые кнопки и настройки

Промежуточная Dev-проверка, 2026-10-26. Ветка: dev.
Это не финальная приёмка релиза; актуальные unsigned KR APK ещё предстоит собрать.

## Изменения

- Кнопка модели и неактивный Send используют серую поверхность из текущей
  палитры. Активный Send сохраняет цвет действия. Серые диски иконок также
  применены в меню «Добавить к сообщению».
- В настройках окрашенная высота кнопок уменьшена с 48 до 38.4 CSS px (20%).
  Область касания остаётся 48 px. Переключатели исключены из этого правила.
- На мобильном экране настроек используется существующий themed select Core:
  скруглённый bottom sheet, отмеченный выбранный пункт, закрытие и клавиатурная
  навигация. Значения, обработчики сохранения и доступные пресеты остаются Core.
  Android native picker вне настроек и настольный вариант сохранены.
- Добавлены тесты actual patched Core select и проверки интерфейса Android.
  Снимки ограничены панелью/меню/настройками; при потере фокуса приложения
  снимок пропускается с PENDING, системные окна не захватываются.
