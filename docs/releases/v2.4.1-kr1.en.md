# Antigravity Android v2.4.1-kr1 — Native Scroll Smoothness Fix

**Independent KR Edition fork · ARM64 · targeted patch on upstream v2.4.0**

## Fixed
* Long conversations no longer exhibited the observed sudden jump / stalled fling on the owner's Android WebView during hands-on testing.
* Only the OverlayScrollbar `ScrollTimeline` feature probe (`G$a()`) is changed to return `null` in generated `web/generated/main.js`.
* The built-in **scroll-event fallback** positions the overlay scrollbar; Chromium native inertial scrolling remains intact.
* The global `ScrollTimeline` API, gesture handling, CSS, GPU layers, Android code and checked-in `web/main.js` are untouched.
* The owner tested long chats and Dark/Light theme and preset switching successfully. This does **not** establish the precise underlying Chromium defect.

## Preserved features
Native agent completion notifications; Hca and NDa stream recovery on background resume; sidebar task-state reconciliation, notification deep links and existing navigation. Showing intermediate agent stages in Android notifications is **not included** and remains on the TODO list.

## Updating from v2.4.0-kr1
1. Choose **one** APK edition: the two variants cannot be installed side by side.
2. Verify its SHA-256 digest.
3. Install it **over** the existing v2.4.0-kr1 app. Do not uninstall or clear app data.
4. Package ID: `com.krmobdev.antigravity`; versionName `2.4.1-kr1`; versionCode `18` (was `17`). Signing certificate SHA-256: `23:AD:AC:86:42:3F:72:98:B0:A8:CC:D4:87:58:E6:E1:9B:E7:65:4D:4F:BD:EC:18:4E:18:4B:7E:16:03:0D:95`.
5. Switching between Standard and bypass also uses an in-place update, retaining the same package and signature. Back up important data before upgrading as a precaution.

The original `com.agy` remains separately installed. Independent fork, not endorsed by [upstream](https://github.com/werdio325-png/antigravity-android).

## Testing and reproducibility
Run `bash web/tests/selftest.sh`, `bash web/tests/test_staged_web_assets.sh`, `bash modules/builder/tests/run_all.sh`, and `bash app/tests/run.sh`. To prepare unsigned artifacts, use `bash modules/builder/build_apk.sh --kr-release --unsigned` (add `--region-bypass` for the alternative). The owner signs interactively in Termux with the **existing permanent** KR release keystore. Never publish unsigned assets.
