# Antigravity Android v2.4.1-kr1 — исправление плавности прокрутки

**Независимый форк KR Edition · ARM64 · исправление поверх upstream v2.4.0**

## Что исправлено
* Устранены наблюдавшиеся скачки длинных чатов и паузы инерционной прокрутки в Android WebView.
* В компоненте OverlayScrollbar отключена **только** проверка доступности ScrollTimeline: функция `G$a()` в собираемом `web/generated/main.js` возвращает `null`.
* Используется **штатный fallback** оверлейного скроллбара на событиях `scroll`; нативный Chromium fling остаётся без изменений.
* Глобальный `ScrollTimeline`, CSS, GPU, Java/Kotlin и обработчики жестов не модифицируются. Исходный `web/main.js` не меняется.
* В ручных испытаниях владельца плавная прокрутка подтверждена в длинных разговорах и при переключении тёмной/светлой темы и пресетов. Это не доказательство конкретной причины внутри Chromium.

## Сохранены возможности предыдущего релиза
Нативные уведомления агентов, восстановление Core-потоков после фона (Hca/NDa), согласование sidebar, deep links и существующая навигация. Показ промежуточных стадий агента в Android-шторке **не реализован**: отдельный TODO на будущее.

## Обновление с v2.4.0-kr1
1. Выберите **одну** редакцию; одновременно установить обе невозможно.
2. Проверьте SHA-256 скачанного файла.
3. Установите новую APK **поверх** версии 2.4.0-kr1, не удаляя приложение и не очищая данные.
4. Package ID: `com.krmobdev.antigravity`; версия: `2.4.1-kr1`; `versionCode: 18` (ранее 17); постоянный сертификат SHA-256: `23:AD:AC:86:42:3F:72:98:B0:A8:CC:D4:87:58:E6:E1:9B:E7:65:4D:4F:BD:EC:18:4E:18:4B:7E:16:03:0D:95`.
5. При замене стандартной версии на bypass (или наоборот) также используйте установку поверх. Состояние и файлы форка должны сохраняться благодаря неизменным package ID и сертификату; резервное копирование перед обновлением рекомендуется.

Оригинал `com.agy` устанавливается отдельно. Релиз независим от [автора оригинального проекта](https://github.com/werdio325-png/antigravity-android).

## Сборка и проверки
`bash web/tests/selftest.sh`, `bash web/tests/test_staged_web_assets.sh`, `bash modules/builder/tests/run_all.sh`, `bash app/tests/run.sh`. Сборка: `bash modules/builder/build_apk.sh --kr-release --unsigned` (или плюс `--region-bypass`); подпись выполняет владелец постоянным ключом отдельно в Termux. Ни один неподписанный файл не должен попадать в GitHub Release.

**Резервная копия ключа вне телефона:** восстановимость пока не подтверждена владельцем, см. `docs/RELEASE_SIGNING_KR.md`.
