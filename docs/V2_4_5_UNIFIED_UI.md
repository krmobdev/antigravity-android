# v2.4.5-kr1 — единый мобильный интерфейс

Изменения от 2026-10-26, только dev. Основа: 9572b4b.
Ориентир владельца — компактные серые меню и скругления из примеров ChatGPT.

## Что изменено

Один слой mobile-interface.css задаёт общий вид меню Core, настроек и их
навигации, обычных кнопок, списка бесед, пользовательских карточек сообщений,
вложений и их просмотрщика. Общие поверхности, границы, скругления и состояния
фокуса вычисляются из действующей темы. Пользовательские цвета не перезаписаны.

«Добавить к сообщению» — компактная плавающая карточка над Composer, с
доступными прежними действиями, прокруткой и закрытием через Back/снаружи.
Положение пересчитывается при изменениях Android visualViewport и размера
панели. ResizeObserver, события и отложенный animation frame снимаются при
закрытии. Другие меню сохраняют существующие Core-контроллеры и вложенную
навигацию; короткие меню получили скругления со всех сторон.

Размеры виртуальных строк и алгоритмы прокрутки не менялись. Изменения не
затрагивают аудиотракт, Core API, значения разрешений, обработчики отправки,
терминал, редакторы, полноэкранные медиа и геометрию role=switch. Desktop CSS
не изменён. Backend-опции не подменяются косметическими пунктами из примера.
