# Antigravity Android v2.4.5-kr1

Кандидат для ручной приёмки владельцем. Без публикации и релизной подписи.

- PTY: надёжный выбор shell и TERM/TERMINFO; перенос исправления upstream
  67670cf со строгой проверкой совместимости бинарника. Реальные Core RPC
  создания, интерактивного ввода, переподключения и повторного открытия проверены.
- Уведомления: последний подтверждённый этап отдельно для каждой беседы,
  объединение частых обновлений, безопасные фиксированные тексты и исходы
  ошибки/отмены. Реальные испытания с экраном блокировки ещё требуют приёмки.
- Вложения: одинаковые карточки, отдельное удаление, просмотр фото и безопасный
  текстовый просмотр, повторный выбор и очистка временных ресурсов.
  Лимит до 5; десять вложений не заявлены без подтверждения Core/API.
- Composer: крупное многострочное поле, области нажатия 48 dp и адаптивное
  меню «+». Сохранены модели, reasoning, голос и прежняя отправка/остановка.
- Исправление нативной прокрутки v2.4.1 сохранено и покрыто регрессиями.
- Package ID `com.krmobdev.antigravity`, versionCode `19`.

Две неподписанные редакции: standard и region-bypass. Они подготовлены для
будущей ручной подписи существующим ключом владельца. Pixel 7, обновление
production и все незавершённые сценарии приёмки указаны в
[handoff](HANDOFF_V2_4_5_KR1.md) и [статусе](V2_4_5_KR1_STATUS.md).
