# Antigravity Android v2.4.5-kr1

> Свежие unsigned-кандидаты подготовлены для ручной подписи владельцем из dev 03b5cf6. Вложения, английский UI и текущий переход из шторки/Back проверены; отдельный legacy-тест старых уведомлений не пройден. Публикация требует отдельной команды владельца.
Проект описания для будущего релиза после ручной приёмки и подписи владельцем.
Этот документ сам по себе не означает публикацию или полное завершение приёмки.

Изменения относительно v2.4.1-kr1:

- PTY-терминал: Android/Termux shell fallback, корректные TERM/TERMINFO и
  upstream-derived бинарный патч с проверкой совместимости, размера, сигнатур
  и повторного применения.
- Этапы агента: последний подтверждённый этап отдельно для каждой беседы,
  тихие обновления существующего уведомления, обработка завершения, ошибок и
  отмены. Неизвестный этап остаётся нейтральным; приватные данные не показываются.
- Вложения: выбор нескольких файлов до фактического лимита Core, максимум 5;
  карточки с превью, просмотр вместо удаления, отдельная кнопка удаления,
  безопасный текстовый просмотр и очистка временных ресурсов.
- Мобильный Composer и меню в едином стиле: компактные модель/effort,
  щит реальных разрешений, адаптивное меню +, удобные Send/Stop, клавиатура и
  светлая/тёмная темы с пользовательскими пресетами.
- Последовательный Back: вложенные меню возвращаются на один уровень;
  корневой Back сворачивает приложение, сохраняя работу Core.
- Desktop Mode адаптируется к портретному экрану; исправлены доступ к настройкам
  и возврат. Кнопка модели центрирована между щитом и микрофоном.
- Сохранена оригинальная голосовая транскрипция Core; нативный Android-захват
  устраняет несовместимость WebView, а ошибки и завершение записи очищают ресурсы.
- Обновление ресурсов WebView не очищает учётные записи и web storage.
- Нативная заставка показывает реальные этапы запуска и Retry. Промежуточная
  тема Core при загрузке больше не перекрашивает системные панели Android.
- Сохранено исправление плавной нативной прокрутки из v2.4.1-kr1.

- Все собственные строки интерфейса — на английском; тексты бесед и имена файлов не изменяются.
- Меню вложений и просмотр больше не меняют историю маршрутов чата; карточки фото и документов одинаковые, с отдельными кнопками удаления 48×48.
- Текущее уведомление возвращает живую Activity/WebView и сохраняет черновик; Back не открывает второй экземпляр прежнего чата.

Package ID: com.krmobdev.antigravity. VersionName: 2.4.5-kr1.
VersionCode: 19, предыдущий стабильный — 18.

Редакции: Standard с исходными локальными проверками доступа Core и
Region-bypass с изменёнными локальными Core gates. Один package ID и ключ:
одновременно установить обе редакции нельзя.

Локальные программные тесты, реальные изолированные PTY RPC и Android UI-проверки
описаны в актуальном отчёте приёмки. Полная проверка настоящих агентов с
выключенным экраном, отправки разных вложений модели, терминального UI,
доступности/длинного чата и обновления production после подписи ещё требует
отдельного подтверждения. Google Pixel 7 исключён владельцем из плана проверок.
